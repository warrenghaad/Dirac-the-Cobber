# The recurring error pattern

Across these events, the same process repeated:

```text
User supplies complex source or reference
        ↓
I identify a few recognizable themes
        ↓
I map those themes to current project features
        ↓
I produce a concise interpretation or task
        ↓
I act as though the interpretation is sufficient
```

The required process was:

```text
User supplies complex source or reference
        ↓
Read the exact source completely
        ↓
Preserve its internal structure and distinctions
        ↓
Map source concepts to the current project
        ↓
Separate observation, inference, adaptation, and recommendation
        ↓
Check for contradictions and omissions
        ↓
Wait for authorization before acting
```

The critical substitution was:

> **theme extraction → action**

where the correct sequence required:

> **source fidelity → project reconciliation → explicit inference → authorization**
